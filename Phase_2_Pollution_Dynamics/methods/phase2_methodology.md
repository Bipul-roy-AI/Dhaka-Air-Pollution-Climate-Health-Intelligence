# Phase 2 Methodology

## Historical Pollution Dynamics Analysis

Study period: 2000-2025

## Trend Analysis

Annual aggregation was performed from daily observations.

Methods:
- Mann-Kendall trend test
- Sen's slope estimator

## Composition Analysis

Methods:
- PM2.5/PM10 ratio
- Pearson correlation
- Spearman correlation
- Principal Component Analysis

## Pollution Regimes

Methods:
- Standardized pollutant features
- K-means clustering
- PCA visualization
- Cluster interpretation

## Regime Evolution

Methods:
- Annual frequency analysis
- Seasonal distribution
- Transition probability matrix

## Episode Analysis

Methods:
- 95th percentile PM2.5 threshold
- Consecutive exceedance detection
- Duration and severity assessment

## Change Point Analysis

Methods:
- Pettitt test
- Rolling anomaly analysis

Phase 2 provides the historical baseline before climate and remote sensing integration.
