# Phase 2 — Historical Pollution Dynamics

## Overview

This phase analyzes the temporal behavior of Dhaka air pollution from 2000–2025 using the processed daily air quality dataset.

## Completed Analyses

### 2.1 Long-term Pollution Trends
Methods:
- Annual aggregation
- Mann–Kendall trend testing
- Sen's slope estimation

Analyzed variables:
- PM2.5
- PM10
- NO2
- SO2
- Ozone
- AQI

### 2.2 Pollution Composition
Methods:
- PM2.5/PM10 ratio analysis
- Pearson correlation
- Spearman correlation
- Principal Component Analysis (PCA)

### 2.3 Pollution Regime Classification
Methods:
- Feature standardization
- K-means clustering
- PCA visualization
- Cluster interpretation

### 2.4 Regime Evolution
Methods:
- Annual regime frequency
- Seasonal regime distribution
- Transition probability analysis

### 2.5 Pollution Episode Detection
Methods:
- 95th percentile PM2.5 threshold
- Consecutive exceedance episode detection
- Duration and seasonal analysis

### 2.6 Change Point Analysis
Methods:
- Pettitt change point test
- Rolling anomaly analysis

## Repository Status

Phase 2 establishes the historical pollution baseline before climate integration and machine learning modelling.
