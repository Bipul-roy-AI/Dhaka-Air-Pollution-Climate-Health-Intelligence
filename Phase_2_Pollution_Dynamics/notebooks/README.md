# Phase 2 Notebooks

This folder contains reproducible analysis notebooks for historical pollution dynamics.

Planned notebooks:

1. 02_trend_analysis.ipynb
   - Annual aggregation
   - Mann-Kendall trend testing
   - Sen slope estimation

2. 03_composition_analysis.ipynb
   - PM2.5/PM10 ratio
   - Correlation analysis
   - PCA

3. 04_pollution_regimes.ipynb
   - K-means clustering
   - PCA visualization

4. 05_regime_evolution.ipynb
   - Annual and seasonal regime frequency
   - Transition analysis

5. 06_episode_detection.ipynb
   - Extreme pollution threshold detection
   - Episode duration analysis

6. 07_change_point_analysis.ipynb
   - Pettitt test
   - Rolling anomaly analysis

The notebooks will be added with executable code as the analysis pipeline is finalized.
